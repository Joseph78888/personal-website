# Technology logomarks

https://github.com/simple-icons/simple-icons/tree/develop/icons

Files: flutter.svg, dart.svg, supabase.svg, firebase.svg, tensorflow.svg, github.svg.
The TensorFlow logomark accompanies the TensorFlow Lite label. Logomarks retain their original paths and are shown in monochrome.
